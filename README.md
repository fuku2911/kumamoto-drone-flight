# Kumamoto Drone Flight

ブラウザだけですぐ遊べる、軽量な3Dドローンゲームを段階的に開発するプロジェクトです。

**Version 0.1（package.json: 0.1.0）**。PCブラウザでSTARTから5個のリングを順番に通過し、完走タイムを確認して繰り返し遊べる最小版です。プレイヤーの登録・ログイン・インストールは不要です。開発とローカル起動には下記のNode.js環境が必要です。

## Play URL

[Kumamoto Drone Flightをプレイする](https://kumamoto-drone-flight.fuku29112000-6f0.workers.dev)

Version 0.1は[GitHubリポジトリ](https://github.com/fuku2911/kumamoto-drone-flight)へPush済みで、Cloudflare Workersで公開済みです。今後は`main`へPushすると、Cloudflareで自動ビルド・デプロイされます。

## 実装済み

- Three.jsによる地面・背景・光源、基本Geometryのクアッドコプター
- 機体基準のキーボード移動・旋回、最低高度、同時入力、フォーカス喪失時の入力解除
- 滑らかな三人称追従カメラとウィンドウサイズ変更への対応
- 初心者向けの5リングコース、順次通過判定、対象・未通過・通過済みの色分け
- READY → PLAYING → FINISHEDの状態管理
- START・操作説明、タイマー・対象リング番号、FINISH・結果表示、RETRYによる全リセット
- 静的配信用のViteビルド

Version 0.1はローカルで動作確認済みです。

## 遊び方

1. READY画面のSTARTを押すと、操作とタイム計測が始まります。
2. 黄色いリングの中心付近を順番に通過します。左上にTIMEと現在対象のCHECKPOINT番号を表示します。
3. 5個目を通過するとFINISHEDになり、操作とタイマーが停止します。中央のFINISH画面に記録を表示します。
4. RETRYで機体・向き・カメラ・リング・時間を初期化し、READYへ戻ります。STARTで再プレイできます。ページ再読み込みは不要です。

時間はperformance.now()による経過時間をMM:SS.xx形式で表示します。タブを離れている時間も計測に含みます。READYとFINISHEDでは機体を操作できません。

## チェックポイント

最初のリングは正面20単位先。その後は前方（-Z）へ26単位ずつ進み、緩やかに右へ曲がるコースです。中心座標は順に(0,8,-20)、(18,9,-46)、(36,10,-72)、(48,9,-98)、(54,8,-124)。高さの変化は隣接リング間で1単位に抑えています。半径は7、管の太さは0.3で、通過しやすい大きさです。

- 明るい黄色（不透明）：現在の対象
- 控えめな青（不透明度40%）：今後の対象
- 薄い緑（不透明度22%）：通過済み

現在の対象の中心から機体中心が3単位以内に入ると通過になり、次のリングが黄色になります。先のリングへ行っても順番は進みません。厳密な面の横断判定ではなく、近距離に入る判定です。5個すべて通過するとFINISH画面に切り替わります。

機体は地面から3単位上空に配置しています。白い中央機体、前後左右の4本のアーム、4個のローターで構成し、オレンジ色の先端・アーム・ローターが前方向（-Z）を示します。外部モデル・画像素材は使用していません。

## 操作

| キー | 動作 |
| --- | --- |
| W / S | 機体基準の前進 / 後退 |
| A / D | 機体基準の左移動 / 右移動 |
| Space / Shift | 上昇 / 下降（左右どちらのShiftにも対応） |
| Q / E | 左旋回 / 右旋回 |

キーを押している間だけ動き、離すと停止します。複数キーを同時に押せます。斜め移動も合計速度は一定で、反対方向のキーは相殺します。別タブへ移動したりウィンドウのフォーカスを失ったりすると入力を解除します。

`src/main.js` 冒頭の `MOVE_SPEED`（6単位/秒）、`TURN_SPEED`（90度/秒）、`MIN_ALTITUDE`（機体中心0.5単位）で調整できます。描画間隔からdeltaTimeを計算し、長い停止後の急移動を防ぐため最大0.05秒に制限しています。ページ再読み込みで初期位置に戻ります。

カメラは機体基準の後方18・上方7を目標位置とし、機体の2単位前方を見ます。`CAMERA_OFFSET`、`CAMERA_LOOK_OFFSET`、`CAMERA_FOLLOW_SPEED`で距離・視線・追従速度を調整できます。時間に基づく補間で滑らかに追いかけ、初期表示は目標位置から開始します。マウス操作・視点切替・ズーム・カメラ衝突判定はありません。

## 開発環境

- Windows / PowerShell
- Node.js 24系（構築時：24.20.0）
- npm（構築時：11.19.0）
- Vite / Vanilla JavaScript / Three.js

## 起動

```powershell
npm.cmd ci
npm.cmd run dev
```

ターミナルに表示されたローカルURLをブラウザで開きます。終了は `Ctrl+C` です。

## ビルドとプレビュー

```powershell
npm.cmd run build
npm.cmd run preview
```

公開用ファイルは `dist/` に出力されます。`wrangler.jsonc`でこのディレクトリを配信対象に指定し、Cloudflare Workers Static Assetsとして公開しています。

## 構成

- `index.html`：ページの入口
- `src/main.js`：設定定数、3D描画、機体・入力・カメラ、リング判定、ゲーム状態、タイマー、UIとリセット
- `src/style.css`：3Dキャンバス、開始・完走パネル、プレイ中HUDの表示
- `AGENTS.md`：継続的な開発ルール
- `DEVELOPMENT_LOG.md`：作業記録

仮タイトルは `src/main.js` の `APP_TITLE` で変更できます。表示にはWebGL 2対応のブラウザ・GPU環境が必要です。

## 動作確認

ブラウザで地面の格子が奥へ向かって細かく見えること、空色の背景が見えることを確認します。ウィンドウを縦長・横長に変更してもキャンバスが追従し、地面が歪まないこと、開発者ツールにエラーがないことを確認します。

中央機体・4本のアーム・4個のローターが見え、機体が地面に埋まらず、オレンジ色の前方向を判別できることを確認します。

各キーで移動・旋回し、旋回後もWがオレンジ色の前方向へ進むこと、W＋Spaceで前進・上昇できること、下降し続けても地面に埋まらないこと、キーを離すと停止することを確認します。

START前は操作できず、STARTで計測開始、5リング完走で操作・計測停止、RETRYでREADYへ戻ることを確認します。再読み込みせず2回以上プレイできることも確認します。
